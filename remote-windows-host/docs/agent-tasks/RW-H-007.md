# RW-H-007 — portable media core (H-MEDIA)

## Outcome

machine-facing parts of PROTOCOL §9 (normative, added by RW-H-006):
binary packet framing, per-window stream key derivation, the stream

interface with a Windows CNG backend. Everything portable must build and

## Requirements

### 1. `media/media_framing.hpp/.cpp` (PROTOCOL §9.4, byte-exact)

Namespace `remotewindows::media`. Constants (match §9.4 exactly):

```
kMediaMagic = 0x52            // 'R'
kMediaFormatVersion = 1
kMediaStreamIdBytes = 2
kMediaGcmTagBytes = 16
kMediaNonceBytes = 12
kMediaNoncePrefixBytes = 8
kMediaMaxPayloadBytes = 16 * 1024 * 1024
kFlagKeyframe = 0x01          // flags bit 0
```

Header layout on the wire — 13 bytes (u8+u8+u16+u8+u32+u32), little-endian:
`u8 magic | u8 version | u16 LE stream_id | u8 flags | u32 LE frame_seq | u32 LE payload_len`.
`payload_len` = ciphertext bytes = plaintext length + 16 (GCM tag
appended). `nonce` (12 B) is never on the wire: `nonce_prefix(8) ||
packet_counter u32 LE`.

API (bool + out-params, no exceptions across the boundary):
- `std::vector<uint8_t> serializeHeader(const MediaHeader& h);`
- `bool parseHeader(const uint8_t* buf, size_t len, MediaHeader& out);`
  false if `len < 14`, magic/version mismatch, or
  `payload_len > kMediaMaxPayloadBytes`.
- `bool streamIdFor(const std::string& window_id, uint16_t& out);`
  first 2 bytes of `core::Sha256` over `window_id`.
- `std::array<uint8_t, kMediaNonceBytes> buildNonce(const std::array<uint8_t, kMediaNoncePrefixBytes>& prefix, uint32_t counter);`

### 2. `media/stream_keys.hpp/.cpp` (PROTOCOL §9.3, exact literals)

- `bool deriveMediaKey(const std::string& session_key_hex, const std::string& window_id, std::array<uint8_t, 32>& key);`
  key = `sha256("rwh-media-v1|" + session_key_hex + "|" + window_id)`
- `bool deriveNoncePrefix(const std::string& session_key_hex, const std::string& window_id, std::array<uint8_t, kMediaNoncePrefixBytes>& prefix);`
  prefix = first 8 bytes of `sha256("rwh-media-nonce-v1|" + session_key_hex + "|" + window_id)`

Must reproduce `protocol/test-vectors/media/key-derivation.json` exactly
(all fields). Load it via the existing `RWH_TEST_VECTORS_DIR` compile
definition (see `tests/CMakeLists.txt:34`) + `nlohmann/json` (already a
dependency of `rwh_core`).

### 3. `media/hmac_sha256.hpp/.cpp` (for the §9.2 handshake)

- `std::array<uint8_t, 32> hmacSha256(const uint8_t* key, size_t key_len, const uint8_t* data, size_t data_len);`
  Standard RFC 2104 two-block construction on top of `core::Sha256`.
  Unit-test with RFC 4231 cases 1 and 2:
  - key = 0x0b × 20, data = `"Hi There"` →
    `b0344c61d8db38535ca8afceaf0bf12b881dc200c9833da726e9376c2e32cff7`
  - key = `"Jefe"`, data = `"what do ya want for nothing?"` →
    `5bdcc146bf60754e6a042426089575c75a003f089d2739839dec58b964ec3843`
  plus a §9.2-shaped case: 64-hex session key decoded to 32 bytes,
  16-byte nonce, message `"rwh-media-v1|" + nonce` — compute the value,
  assert it is a stable 32-byte hex (self-consistency), do NOT invent a
  golden value.

### 4. `media/aead.hpp` + `media/aead_cng.cpp`

Interface (portable, header-only class):
```
class IAead {
 public:
  virtual ~IAead() = default;
  // Seal: out buffer must hold in_len + kMediaGcmTagBytes.
  virtual bool seal(const uint8_t key[32], const uint8_t nonce[12],
                    const uint8_t* in, size_t in_len,
                    uint8_t* out_ct_tag, size_t& out_len) const = 0;
  // Open: in is ciphertext+tag (in_len >= kMediaGcmTagBytes);
  // out holds at least in_len - kMediaGcmTagBytes. Returns false on
  // any authentication failure (never partially writes).
  virtual bool open(const uint8_t key[32], const uint8_t nonce[12],
                    const uint8_t* in, size_t in_len,
                    uint8_t* out_pt, size_t& out_len) const = 0;
};
```

`AeadCng` (WIN32-only translation unit, `media/aead_cng.cpp`, declared in
a separate `media/aead_cng.hpp` with an `#ifdef _WIN32` guard):
- `BCryptOpenAlgorithmProvider(NULL, BCRYPT_AES_ALGORITHM, NULL, 0)` +
  `BCryptSetProperty(..., BCRYPT_CHAINING_MODE, BCRYPT_CHAIN_MODE_GCM, ...)`
  + `BCryptCreateKey(..., key, 32, ...)` per call; `BCryptEncrypt(key,
  out, in_len + 16, 0, nonce, 12, NULL, 0, out_len, 0)` (tag is written
  at the end of the output buffer) and `BCryptDecrypt` symmetrically.
- Thread-safe: create/destroy the algorithm+key objects inside each
  call; no member state.
- Include order per the `app/Win32Env.hpp` pattern (NOMINMAX,
  `_WIN32_WINNT` set, `<windows.h>` before `<bcrypt.h>`); link
  `bcrypt` on WIN32 in CMake.

### 5. `media/stream_registry.hpp/.cpp` (PROTOCOL §9.5)

```
struct MediaStream {
  std::string window_id;
  uint16_t stream_id = 0;
  std::array<uint8_t, 32> key{};
  std::array<uint8_t, kMediaNoncePrefixBytes> nonce_prefix{};
  uint32_t packet_counter = 0;   // consumed by buildNonce, then incremented
  uint32_t frame_seq = 0;        // reset on (re)add; incremented per encoded frame
  bool keyframe_due = true;
  core::FpsGate fps_gate;
};
class StreamRegistry {
  bool add(const std::string& window_id, const std::string& session_key_hex);  // idempotent: re-derives state, resets counters
  bool remove(const std::string& window_id);
  const MediaStream* find(const std::string& window_id) const;
  const MediaStream* findByStreamId(uint16_t stream_id) const;
  size_t size() const;
};
```
Thread-safe with a `std::mutex` (the media server will call from the
accept thread and capture threads). `add` returns false only on key
derivation failure. Invariants: unique `stream_id` per registered
window (document the 16-bit collision behavior: last add wins, find is
by exact window_id first); `frame_seq`/`packet_counter` are
per-connection per-stream and reset on `add`.
